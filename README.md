## Description

A multi-page static website dedicated to tea culture. The site includes a main page with an overview of tea types and individual pages for each type.

## Pages

- **Home** (`index.html`) — general information about tea, fun facts, interactive tea map
- **Matcha** (`matcha.html`)
- **Puer** (`puer.html`)
- **Oolong** (`oolong.html`)
- **Hibiscus** (`carcade.html`)

## Technologies

- HTML5
- CSS3
